# سِكّة البن

طيار عربي لاختيار نوع البن والطحن ووزن الشحنة وتواترها وحفظ مسودة محليًا. العلامة والمنتجات والأسعار افتراضية. يعمل النموذج دون بيانات تواصل أو وسيلة دفع. الصورة مولدة للمشروع وخط Noto Sans Arabic مرخص بـ SIL OFL. ملف الترخيص مع الأصل.

## التشغيل

من مجلد `pilot` ومع Node 24 أو أحدث:

```sh
PORT=48732 npm start
```

افتح [المعاينة المحلية](http://127.0.0.1:48732). استخدم عنوان `127.0.0.1` المحدد في سطر بدء التشغيل. يربط الخادم بالواجهة المحلية. يحفظ افتراضيًا في `.data/drafts.sqlite`، ويمكن ضبط `PILOT_DB` لمسار بديل. عمر السجل نحو سبعة أيام، ويتحقق الحذف عند تشغيل الخادم ثم مرة كل ساعة ما دام يعمل. يحتفظ النموذج بمرجع الحفظ في الصفحة الحالية. تفتح زيارة جديدة نموذجًا جديدًا.

## التحقق

```sh
npm run check
npm test
cd qa
npm ci --ignore-scripts
./node_modules/.bin/playwright install webkit
npm run browser
npm run lighthouse
```

يلزم Google Chrome لفحص Chrome وLighthouse. اترك الخادم يعمل أثناء اختبار المتصفح. لعنوان تشغيل مغاير اضبط `PILOT_URL`. يكتب التحقق الافتراضي التقارير في `../../evidence` من مجلد QA، ويمكن تغيير الموقع بـ `PILOT_EVIDENCE`. اضبط `PILOT_DB` في أمر اختبار المتصفح إلى **مسار مطلق** لقاعدة خادم الاختبار إذا أردت فحص السجل الفعلي مباشرة. اختبارات الخادم توفر قاعدة مؤقتة وتنتج اختبارات مستقلة للكتابة والنسخ والاستعادة.

## البنية

تتشارك الواجهة والخادم كتالوج خيارات ثابتًا. يتحقق الخادم من الحقول والأصل والحجم، ويحسب سعر المسودة ويحفظها في جدول SQLite. يرسل العميل مفتاحًا فريدًا لعملية الحفظ، وتعيد المحاولة بالمفتاح نفسه المرجع الحالي إن لم تتغير الخيارات. حدود الطلبات والنشر والفهرسة مصممة للطيار المحلي.

تحويل النموذج إلى متجر يتطلب اعتماد الكتالوج والأسعار والهوية وربط الدفع والشحن والفوترة والحسابات وفق نطاق العميل، وقياس الاستخدام، وتحديد سياسات التشغيل والاحتفاظ والصلاحيات ومراجعة جاهزية النشر.

## معاينة GitHub Pages

[افتح الموقع المنشور](https://az212z.github.io/sikkat-albun/). تحفظ المعاينة آخر مسودة في المتصفح نفسه وتستعيد اختياراتها خلال سبعة أيام إذا بقيت بيانات الموقع محفوظة. لتحديثها شغّل `npm run build:pages` والتزم بملفات `docs/` الناتجة. النسخة المحلية توثّق مسار Node وSQLite أعلاه.
